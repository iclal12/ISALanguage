# Turkish Programming Language

A Turkish-inspired programming language developed as part of the Data Structures course.

## Features

- Variable declarations
- Conditional statements
- Loops
- Functions
- Arithmetic operations
- Custom syntax inspired by Turkish keywords

## Technologies

- Parsing
- Compiler Concepts
